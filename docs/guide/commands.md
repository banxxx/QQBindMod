# 游戏内与机器人命令

## 游戏内 `/qqbind`

游戏内命令需要管理员权限（通常为权限等级 4，服务器控制台也可以执行）。

| 命令 | 说明 |
| --- | --- |
| `/qqbind status` | 查看当前绑定运行时状态、配置加载状态和官方就绪状态。 |
| `/qqbind reload` | 重新加载配置和绑定数据。只适用于允许热重载的字段；端口、存储模式、平台和官方运行期参数需要完整停启。 |
| `/qqbind list` | 列出当前绑定记录。 |
| `/qqbind unbind <gameId>` | 解绑指定游戏 ID。 |
| `/qqbind operation <operationId>` | 查看某个官方操作。 |
| `/qqbind operation <operationId> retry` | 重试官方操作。 |
| `/qqbind operation <operationId> cancel` | 取消官方操作。 |
| `/qqbind reconcile` | 将官方镜像与预占状态对账；未决绑定不会自动提交。 |

`operation` 和 `reconcile` 主要面向 QQ 官方模式。官方绑定运行时未就绪时，命令会返回失败提示。

## QQ 机器人命令

以下命令需要配套的 QQ 机器人插件支持，实际前缀、权限和文案以插件为准：

| 命令 | 说明 |
| --- | --- |
| `/绑定` 或 `/bind <6位令牌>` | 使用游戏内显示的令牌完成绑定。 |
| `/解绑` 或 `/unbind <游戏ID>` | 解绑，通常仅管理员可用。 |
| `/查绑定` 或 `/check <游戏ID>` | 查询游戏 ID 的绑定状态。 |
| `/查绑定 QQ <QQ号>` | 通过 QQ 号查询绑定的游戏 ID。 |
| `/在线` 或 `/status` | 查看在线玩家。 |
| `/广播 <消息>` | 向全服广播。 |
| `/tps` | 查看服务器 TPS。 |

## 绑定流程

1. 未绑定玩家进入服务器，看到标题/动作栏提示。
2. OneBot 模式下，玩家在 `{groupHint}` 指定的 QQ 群发送 `/绑定 <6位令牌>`。
3. QQ 官方模式下，玩家按提示在官方群发送 `/mc bind <绑定码>`；具体命令以插件为准。
4. 机器人插件调用模组接口完成绑定。
5. 绑定成功后，玩家自动加入原版白名单，并收到成功提示。

## 解绑与白名单

解绑后：

- 绑定关系从存储中移除；
- 原版白名单自动移除；
- 如果玩家在线，后续登录会重新受到未绑定拦截（取决于 `enableWhitelistCheck`）。

如果解绑后仍能进入服务器，检查：

- 是否解绑了正确的游戏 ID / QQ；
- 是否为混合模式且中心库同步失败；
- 服务端是否还有其他白名单来源；
- `enableWhitelistCheck` 是否为 `false`，或玩家是否为 OP。
